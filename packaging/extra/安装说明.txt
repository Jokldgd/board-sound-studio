Soundboard Studio 1.1.0 安装说明（给测试人员）
================================================

一、怎么装（只要三步）

  1. 把整个文件夹解压到本机（不要直接在压缩包里双击）。
  2. 双击「安装.cmd」（会弹一次 UAC，点“是”）。
     —— 如果双击 exe 报“无法创建临时目录 / 错误 5”，也必须用这个 cmd，
        它会把临时目录指到 C:\ProgramData，绕开该问题。
  3. 一路“下一步”，在“附加任务”页保持「安装 VB-CABLE 虚拟声卡」勾选。

  安装过程中会自动静默安装 VB-CABLE；如果系统里已经有虚拟声卡，
  安装程序会自动取消勾选并提示“无需重复安装”。

二、装完为什么可能“听不到/看不到虚拟声卡”

  VB-CABLE 是音频驱动，装完通常需要【重启一次】，系统里才会出现：
     播放设备：CABLE Input (VB-Audio Virtual Cable)
     录音设备：CABLE Output (VB-Audio Virtual Cable)

  安装程序会自动检查这两个端点：
   - 两个都在  → 提示“虚拟声卡已就绪”
   - 缺任意一个 → 提示“需要重启”，可以直接点“是”立即重启（15 秒后重启）

  重启后如果还是没有，用开始菜单里的：
     Soundboard Studio → 安装/修复 VB-CABLE 虚拟声卡
  这个脚本会重新以管理员身份装一次驱动，并打印两个端点的检测结果。

三、装完之后怎么用（OOPZ / Discord / 游戏）

  1. 打开 Soundboard Studio；
  2. 顶栏路由保持「虚拟声卡（推荐）」；
  3. 语音软件的“麦克风/输入设备”选：CABLE Output (VB-Audio Virtual Cable)；
  4. 想本地也听到音效（又不想听到自己说话）：顶栏 🎙 → 勾选
     「本地也播放音效（不含麦克风）」。

四、安装位置与数据

  程序目录：C:\Program Files\Soundboard Studio
  你的录音、config.json、studio.log 都在这个目录下（可正常写入）。
  卸载不会删除 audio\ 里的录音。

五、常见问题

  Q: 双击 exe 报错 5 / 无法创建临时目录？
  A: 用「安装.cmd」启动（见第一步）。

  Q: 装完提示“虚拟声卡没就绪”？
  A: 重启电脑；还不行就用开始菜单的「安装/修复 VB-CABLE 虚拟声卡」。

  Q: 杀毒软件拦截？
  A: 安装包未做代码签名，属正常现象；选择“允许/仍要运行”，
     或把安装目录加入杀软白名单。

  Q: 装的时候提示 VB-CABLE 已经被别的程序占用 / 安装失败？
  A: 先重启一次，再运行开始菜单的「安装/修复 VB-CABLE 虚拟声卡」。
